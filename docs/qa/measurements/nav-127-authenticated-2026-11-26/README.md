# #127：登录后首页导航加载采样

2026-11-26，产品源码 `fe32a637d`，探针来自 `9c1320664`。用户在独立测试包内真实登录后测量，没有旧版 A/B 数据，不作为性能改善结论。

## 环境与方法

与[未登录采样](../nav-127-anonymous-2026-11-26/README.md)采用相同设备和方法：DN-ENG41 / SM6225、Android 14、60Hz、Flutter 3.47.9、arm64 profile/AOT、浅色主题、64 逻辑像素悬浮玻璃底栏、关闭首页切换动画。充电、电量 100%，电池温度开始 28.5°C、十轮结束 28.7°C、补测后 28.9°C。

每页五次新进程，各先展示首页 6 秒，再首次进入和回访两次；每页首次 n=5、回访 n=10。保留账号、图片及磁盘缓存；“我的”可能先展示已缓存的用户信息。相同网络，实时响应与图片未冻结，因此登录/未登录的差异包含内容变化，不能视作受控 A/B。

起点是实际导航回调，不包含物理触摸分发时间。首帧采用可见页面合成帧对应的 `FrameTiming.rasterFinish`，不是面板展示时刻；UI/Raster 是整帧耗时，不能全归到目标页。`data_terminal` 是页面到位后 10ms 轮询观察到的终态，精确请求 await 返回另记 `request_result`。记录器开销未扣除。

十轮中动态第三轮缺少首帧 107 对应的 FrameTiming，汇总校验拒绝，保留在 `rejected/`；补测同一页面的新进程，使用补测的完整三条替换该轮，未按耗时选择样本。补测脚本附带的额外“我的”一轮不计入正式结果。

## 登录与未登录对照

下表仅汇总首次进入的中位数；边界与限制同上。

| 动态 | 未登录 | 92.83 | 196.62（未登录错误） |
| 动态 | 已登录 | 80.98 | 409.35（成功） |
| 我的 | 未登录 | 64.18 | 不适用：不请求 |
| 我的 | 已登录 | 96.89 | 227.20（成功） |

这四组数据支持首次进入有额外帧开销；登录后动态内容需等待约 0.4 秒，但首帧光栅在请求完成前已结束，所以不能说首帧被网络请求阻塞。登录后的“我的”首帧比匿名样本慢，具体来自哪些构建、图片或玻璃开销，仍需调用栈/时间线拆解。

当前没有旧版对照、其他底栏样式及动画开启时的测量，不能据此宣布 #127 全部解决。
